API Deprecation Policy

How we evolve the API without breaking production integrations.

Contract Stability (v1)

Fields in existing v1 responses are additive-only. We do not remove or rename response keys inside v1.

Deprecation Window

Deprecated endpoints receive at least 90 days notice before removal. During this period, responses include:

  • Deprecation: true
  • Sunset date in RFC 7231 format
  • Link header pointing to the successor endpoint

Version Lifecycle

New breaking changes ship under a new path version (/api/v2/...). Older versions continue for the announced sunset period.
